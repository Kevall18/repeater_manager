# Repeater Manager

A Flutter multi-platform app for managing repeaters with support for Android, iOS, Web, and Windows.

## Supported Platforms

- Android
- iOS
- Web
- Windows

## Getting Started

### Prerequisites

- Flutter SDK (version 3.0.0 or later)
- Chrome browser (for web development)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kevall18/repeater_manager.git
   cd repeater_manager
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

### Running the App

#### Web (Chrome)
```bash
flutter run -d chrome
```

#### Android
```bash
flutter run -d android
```

#### iOS
```bash
flutter run -d ios
```

#### Windows
```bash
flutter run -d windows
```

## Features

- Counter app with Flutter Material Design
- Cross-platform support (Android, iOS, Web, Windows)
- Responsive UI

## Project Structure

- `lib/` - Dart source code
- `android/` - Android platform configuration
- `ios/` - iOS platform configuration
- `web/` - Web platform configuration
- `windows/` - Windows platform configuration
- `pubspec.yaml` - Project dependencies and metadata
